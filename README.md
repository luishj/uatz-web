# uatz-web

Frontend do projeto UATZ construído com Angular.

## Escopo inicial

- Login
- Dashboard
- Pedidos de orcamento
- Vendedores
- Historico de cotacoes

## Como rodar futuramente

Prerequisitos locais:

- Node.js 22+
- npm 11+

Instalacao e execucao:

```powershell
npm install
npm start
```
